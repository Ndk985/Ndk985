## 💼 Основные направления и реализованные решения

### 🏗️ Корпоративные backend-системы и data-платформы
Разработка enterprise-систем для управления товарными каталогами и бизнес-данными: импорт данных из HTTP/FTP/Excel/веб-источников, автоматический парсинг и нормализация, AI-обогащение через LLM, сопоставление товаров, гибкая система характеристик, мультитенантная архитектура, экспорт в CSV/XLS/XML/YAML. Работа с большими объёмами данных, асинхронными задачами и поисковыми индексами.

### ⚡ Асинхронные сервисы, очереди и фоновые задачи
Проектирование событийных backend-систем с Celery, Redis и RabbitMQ: триггерные email-уведомления, массовые рассылки, обработка событий из legacy-баз данных, повторная доставка, отказоустойчивость и масштабирование фоновых процессов.

### 🌐 REST API и backend-платформы
Разработка REST API для социальных платформ, маркетплейсов и сервисов бронирования: ролевые модели доступа, JWT-аутентификация, пагинация, фильтрация, загрузка файлов, масштабируемая архитектура и production-развёртывание через Docker и Nginx.

### 🔗 Интеграции, боты и автоматизация
Интеграция backend-сервисов с Telegram Bot API, Google APIs и внешними платформами: автоматизация бизнес-процессов, уведомления пользователей, отчётность и синхронизация данных между системами.

### 🧩 Парсинг, ETL и обработка данных
Разработка парсеров и ETL-пайплайнов для структурированных и неструктурированных источников: Scrapy, BeautifulSoup, Excel/CSV, кеширование запросов, логирование, нормализация данных и экспорт в аналитические форматы.
